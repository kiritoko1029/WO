# WO UI 全面系统化升级 — Indigo 柔和现代风（Soft UI Evolution）

## 目标与原则

1. **Token 化**：把散落的 30+ 硬编码色值收敛为 CSS 变量系统（颜色/圆角/阴影/间距/动效），未来换肤、做深色模式只需改 `:root`。
2. **Indigo 柔和现代风**：主色从 `#2962ff`（蓝）切到 `#6366f1`（indigo-500），配 success green `#10b981`，Soft UI 阴影分层。背景用 slate-50 中性色（**不**用纯 indigo-50 大面积淡紫，避免通话界面久看疲劳）。
3. **微交互**：所有 `:hover`/`:focus`/状态切换加 150–250ms `cubic-bezier` 过渡，消除"瞬时跳变"的廉价感。
4. **零破坏**：保留全部 className 名与 DOM 结构，测试零改动；只动 CSS 内容 + 极少量 JSX 视觉增强。
5. **Web 端补齐**：修正 `color-scheme: dark` bug，补齐 `web.css` 缺失样式，让 web 与桌面视觉统一。

## 验证基础（已确认）

- 所有测试用 `role` / `aria-label` / 中文文字 / `data-testid`，**不依赖任何 class 名** → CSS 自由重构
- web `main.tsx` 复用 desktop `styles.css` → **改一处，两端生效**

## 改动 1：`styles.css` 完整重构（核心，约 +80 行 token / 改写 ~400 行规则）

### 1.1 新增 `:root` 设计 Token（文件顶部）

```css
:root {
  /* Indigo 品牌色阶（50→700） */
  --wo-brand-500: #6366f1;  /* 主色 */
  --wo-brand-600: #4f46e5;  /* hover */
  --wo-brand-700: #4338ca;
  --wo-brand-50:  #eef2ff;  /* soft bg */
  --wo-brand-100: #e0e7ff;
  --wo-brand-200: #c7d2fe;

  /* 语义色 */
  --wo-success: #10b981; --wo-success-soft: #d1fae5;  /* 已连接 */
  --wo-warning: #f59e0b; --wo-warning-soft: #fef3c7;  /* connecting */
  --wo-danger:  #ef4444; --wo-danger-soft:  #fee2e2;  /* 挂断/错误 */
  --wo-info:    #0ea5e9;                              /* relay 中继 */

  /* 中性色 slate（不用纯 indigo 大面积铺底） */
  --wo-bg: #f8fafc; --wo-surface: #ffffff;
  --wo-surface-2: #f1f5f9; --wo-surface-3: #e2e8f0;
  --wo-border: #e2e8f0; --wo-border-strong: #cbd5e1;
  --wo-text: #0f172a; --wo-text-muted: #475569;
  --wo-text-subtle: #64748b; --wo-text-faint: #94a3b8;

  /* 通话舞台暗色（沉浸感，indigo 偏冷的 slate-900） */
  --wo-stage-bg: #0f172a; --wo-stage-surface: #1e293b;
  --wo-stage-border: #334155; --wo-stage-text: #e2e8f0;

  /* 圆角 / 阴影 / 间距 / 动效 */
  --wo-radius-sm: 6px; --wo-radius-md: 8px; --wo-radius-lg: 12px; --wo-radius-pill: 999px;
  --wo-shadow-sm: 0 1px 3px rgb(15 23 42 / .08), 0 1px 2px rgb(15 23 42 / .04);
  --wo-shadow-md: 0 4px 12px rgb(15 23 42 / .08), 0 2px 4px rgb(15 23 42 / .04);
  --wo-shadow-lg: 0 12px 32px rgb(15 23 42 / .12), 0 4px 8px rgb(15 23 42 / .04);
  --wo-ease: cubic-bezier(.4, 0, .2, 1);
  --wo-dur: 200ms; --wo-dur-fast: 150ms;
}
```

### 1.2 全文替换所有硬编码色 → token

逐一映射现有色值到 token（示例）：
- `#2962ff` / `#1f50d7` / `#2558df` / `#1749bd` → `var(--wo-brand-500/600)`
- `#eef1f3` / `#f4f6f7` / `#edf0f2` → `var(--wo-bg)` / `var(--wo-surface-2)`
- `#1f252b` / `#14191e` → `var(--wo-text)`
- `#66717a` / `#58636c` / `#737e86` 等 10+ 灰 → `var(--wo-text-muted)` / `var(--wo-text-subtle)`
- `#bd2935` / `#d63845` → `var(--wo-danger)`
- `#138a80` / `#1aa27a` / `#0d766e` → `var(--wo-success)`
- `#d39c22` → `var(--wo-warning)`, `#1677a8` → `var(--wo-info)`
- 房间舞台 `#191d21` / `#2b3136` / `#14181b` → `var(--wo-stage-bg/surface)`

### 1.3 全局微交互注入

- `button`、`input`、`.icon-button`、`.tool-button`、`.primary-button` 等所有交互元素：加 `transition: background-color var(--wo-dur) var(--wo-ease), border-color var(--wo-dur) var(--wo-ease), color var(--wo-dur) var(--wo-ease), box-shadow var(--wo-dur) var(--wo-ease), transform var(--wo-dur-fast) var(--wo-ease);`
- `:focus-visible` 改用 `box-shadow: var(--wo-shadow-focus)` + `outline: 2px solid var(--wo-brand-500)`（indigo 焦点环）
- hover 用**轻微 `translateY(-1px)` + 阴影升级**而非颜色突变（Soft UI 特色），并保留 `prefers-reduced-motion` 兜底

## 风险评估

- **风险等级：低**。纯 CSS + 3 处 meta 标签改动，无逻辑变更，测试选择器零冲突。
- 最大潜在问题：某处 hover 过渡时长体感不适 → 可在验收时微调 `--wo-dur`。
- 色值映射若有遗漏（个别硬编码色未替换），会在目检时发现并补齐。
